1.1 Por que aprender a programar?

O primeiro passo é querer começar

🎯 Tudo começa com vontade

Aprender a programar não exige nenhum talento sobrenatural. Não é preciso ser gênio em matemática, ter nascido “sabendo” ou já ter alguma experiência com computadores. O primeiro ingrediente é simples: vontade.

Quando decidimos aprender algo novo, a parte mais difícil costuma ser dar o primeiro passo. Com programação não é diferente. Mas a boa notícia é que qualquer pessoa pode aprender — e o caminho é mais acessível do que parece.

💪 Dedicação importa mais que talento

Programação se aprende fazendo. Não basta ler ou assistir — você precisa colocar a mão na massa, digitar código, errar, corrigir e tentar de novo. Esse ciclo de tentativa e erro é o verdadeiro motor do aprendizado.

💬

“Aprender a programar é como aprender um idioma novo: no começo parece impossível, mas com prática tudo começa a fazer sentido.”

O importante é manter a consistência. Um pouco a cada dia é mais eficiente do que tentar aprender tudo de uma vez. A dedicação contínua transforma o difícil em natural.

🧠 Programar muda sua forma de pensar

Mais do que escrever código, programar ensina você a:

  • Decompor problemas — dividir algo grande em partes menores e resolvíveis
  • Pensar logicamente — encadear passos de forma organizada
  • Resolver problemas criativamente — encontrar soluções que outros não veem
  • Comunicar ideias com precisão — computadores exigem clareza absoluta

Essas habilidades são úteis em qualquer área da vida, não apenas na computação. Por isso se diz que programar é a nova alfabetização.

1.2 Paciência: a virtude do programador

Começar simples é começar certo

👶 Comece pelo básico

Ao aprender a programar, é tentador querer criar um aplicativo completo logo de cara. Mas assim como não começamos a ler por um romance de 500 páginas, em programação começamos pelo simples.

Os primeiros programas serão pequenos. Talvez pareçam até “bobos”. Mas cada programa simples ensina um conceito fundamental que será usado para sempre. Dominar o básico é o que separa quem desiste de quem avança.

🔍 Atenção aos detalhes

Computadores são extremamente literais. Eles fazem exatamente o que você manda — nem mais, nem menos. Um ponto-e-vírgula fora do lugar, um parêntese esquecido ou uma letra maiúscula onde deveria ser minúscula podem causar erros.

Isso pode ser frustrante no início, mas desenvolve uma habilidade valiosa: atenção aos detalhes. Com o tempo, seus olhos se treinam a identificar problemas rapidamente.

💬

“O computador não faz o que você quer — ele faz o que você manda. A diferença entre os dois é onde mora o bug.”

🚨 Errar faz parte (e é bom!)

Se tem uma certeza em programação, é esta: você vai errar. Muito. E tudo bem.

Mensagens de erro não são punições — são pistas. Cada erro é uma oportunidade de entender melhor como o computador funciona. Os melhores programadores não são os que não erram, mas os que sabem interpretar e corrigir erros rapidamente.

Dicas para lidar com erros:

  • Leia a mensagem de erro inteira — ela quase sempre diz o que aconteceu e onde
  • Não entre em pânico — respire e releia o código com calma
  • Compare com exemplos que funcionam — encontre a diferença
  • Pesquise o erro — milhões de pessoas já tiveram o mesmo problema

1.3 Tempo de estudo e ritmo

Pouco e frequente vence muito e raro

📆 Sessões curtas e frequentes

Estudos mostram que o cérebro aprende melhor em sessões curtas e regulares do que em maratonas longas e esporádicas. Para programação, isso é especialmente verdade.

30 a 45 minutos por dia, todos os dias, produz resultados melhores do que 5 horas seguidas uma vez por semana. O segredo está na repetição espaçada — seu cérebro precisa de tempo para consolidar o que aprendeu.

📖
Leia 10 min de teoria

🎨 Encontre seu estilo

Cada pessoa aprende de um jeito. Alguns preferem ler, outros preferem vídeos, e há quem aprenda melhor fazendo direto. Não existe estilo “certo” ou “errado” — o importante é descobrir o que funciona para você.

Experimente combinar diferentes abordagens:

  • Leitura — o livro-texto e documentação
  • Vídeos — tutoriais visuais para conceitos difíceis
  • Prática guiada — digitar os exemplos do livro
  • Projetos pessoais — criar algo que você quer resolver
  • Estudo em grupo — explicar para outros reforça seu aprendizado

🧘 Mantenha a calma

É normal se sentir perdido no início. É normal achar que “todo mundo entende menos eu”. Isso tem até um nome: síndrome do impostor. E é muito mais comum do que você imagina.

💬

“Não compare seu capítulo 1 com o capítulo 20 de outra pessoa. Todo especialista já foi iniciante.”

O aprendizado não é linear. Terá dias bons e dias difíceis. O importante é não desistir nos dias difíceis. Dê uma pausa, respire, e volte depois. O código vai estar lá esperando.

1.5 Por que Python?

A linguagem que conquistou o mundo pela simplicidade

✨ Simplicidade e legibilidade

Python foi criada por Guido van Rossum em 1991 com um objetivo claro: ser uma linguagem fácil de ler e escrever. Enquanto outras linguagens usam chaves, ponto-e-vírgula e símbolos complicados, Python usa indentação e palavras que parecem inglês.

🐍 Python if idade >= 18: print("Maior de idade") else: print("Menor de idade")
☕ Java if (idade >= 18) { System.out.println("Maior de idade"); } else { System.out.println("Menor de idade"); }

Percebeu a diferença? O código Python é mais limpo, mais curto e mais próximo do português. Isso não é acidente — é filosofia de design.

🔋 “Batteries Included”

Python vem com uma biblioteca padrão enorme — isso significa que muita coisa já vem pronta para usar, sem precisar instalar nada extra. Os programadores chamam isso de “batteries included” (pilhas inclusas).

2.1 Instalação do Python

Seções 2.1, 2.1.1, 2.1.2, 2.1.3 — Colocando o Python na sua máquina

🧰 O que é o interpretador?

Antes de programar, precisamos instalar o interpretador Python. Ele é o programa que aceita comandos escritos em Python e os executa, linha a linha. É ele quem traduz nossos programas em um formato que o computador entende.

Sem o interpretador, nossos programas seriam apenas texto. Ele também verifica se escrevemos corretamente, mostrando mensagens de erro quando encontra algum problema.

💬

“O interpretador Python é como um tradutor: você fala em Python, ele traduz para o computador executar.”

🖥 Instalando no Windows

O Python está disponível gratuitamente no site oficial. Veja o passo a passo:

  1. Acesse python.org e clique em Downloads
  2. Baixe a versão mais recente do Python 3 (ex: Python 3.12)
  3. Execute o instalador baixado (.exe)
  4. IMPORTANTE: Marque a opção “Add Python to PATH” antes de clicar em Install
  5. Escolha “Install for all users” (recomendado)
  6. Aceite o diretório padrão ou escolha outro local
  7. Aguarde a barra de progresso completar
  8. Clique em Finish para concluir
💬

⚠ Dica importante: Marcar “Add Python to PATH” evita muita dor de cabeça depois. Se esqueceu, reinstale marcando essa opção.

A maioria das distribuições Linux já vem com Python instalado. Para verificar a versão, abra o terminal e digite:

2.2 Usando o Interpretador (IDLE)

Seu playground para testar código Python

🎮 O que é o IDLE?

O IDLE é a interface gráfica que acompanha o Python. Ele permite editar e executar programas de forma simples, tudo num só lugar.

Como abrir o IDLE:

  • Windows: Menu Iniciar → Python 3.x → IDLE
  • Linux: No terminal, digite idle-python3 ou idle3
  • Mac: No terminal, digite IDLE3 ou idle3

Ao abrir o IDLE, você verá a janela do interpretador (Python Shell). Repare no símbolo >>> — ele indica que o Python está pronto para receber um comando.

2.3 Editando e Salvando Programas

Seções 2.3 e 2.4 — Do interpretador ao seu primeiro arquivo .py

📄 Interpretador vs. Editor de Textos

Até agora, digitamos comandos diretamente no interpretador. Isso é ótimo para testes rápidos, mas para programas maiores precisamos de arquivos.

Um programa Python nada mais é que um arquivo-texto escrito em um formato especial (a linguagem Python). Podemos usar qualquer editor de textos: o próprio IDLE, VS Code, Sublime Text, Vim, etc.

⚠️

⚠ Nunca use o Microsoft Word ou LibreOffice Writer! Esses editores gravam arquivos em formatos especiais que não servem para programar. Use sempre um editor de código ou o próprio IDLE.

💾 Criando seu primeiro arquivo no IDLE

O IDLE tem seu próprio editor de textos embutido. Siga os passos:

  1. Com o IDLE aberto, clique no menu File → New File (Ctrl+N)
  2. Uma nova janela se abre — essa é a janela do editor de textos
  3. Digite seu programa:
    teste.pyprint("Oi")
  4. Salve com File → Save (Ctrl+S). Nomeie como teste.py
  5. Execute com Run → Run Module (F5)

O resultado aparecerá na janela do interpretador (Python Shell). Você verá a palavra RESTART seguida do resultado Oi.

💬

💡 Lembre-se: a extensão .py não é adicionada automaticamente pelo IDLE. Sempre salve seus programas com a extensão .py!

⚠ Cuidados ao digitar programas

Ao digitar um programa, preste atenção nestes detalhes:

  • Maiúsculas e minúsculas são diferentes — print funciona, Print dá erro. Python é case-sensitive
  • Aspas devem ser abertas e fechadas — toda vez que abrir aspas, feche-as. O IDLE muda a cor do texto entre aspas para ajudar
  • Parênteses não são opcionais — não remova os parênteses das funções. Preste a mesma atenção que dá às aspas
  • Espaços são muito importantes — Python usa a indentação (espaços no início da linha) para organizar o código. Nunca junte duas linhas em uma só
💬

“Organize seus programas em uma pasta específica no computador. Crie um diretório para cada capítulo. Com o tempo, essa organização vai facilitar muito.”

2.5 Variáveis e Atribuição

Guardando valores na memória do computador

📦 O que são variáveis?

Além de cálculos simples, o interpretador também pode executar programas completos. Para isso, precisamos entender o conceito de variáveis.

Na matemática, usamos incógnitas como x e y. Em programação, variáveis funcionam de forma parecida: são nomes que dão acesso a uma área da memória do computador onde armazenamos dados.

Imagine a memória como uma grande estante com compartimentos. Cada compartimento tem um nome. Para guardar algo, usamos o símbolo de igualdade (=). Chamamos isso de atribuição: a variável recebe um valor.

✍ Primeiro programa com variáveis

Observe este programa simples:

Listagem 2.7a = 2 # a recebe 2
b = 3 # b recebe 3
print(a + b)  # exibe a soma

Linha por linha:

  • a = 2 — Cria uma variável chamada a e armazena o valor 2
  • b = 3 — Cria uma variável chamada b e armazena o valor 3
  • print(a + b) — Calcula a + b e exibe o resultado: 5

Você pode testar isso direto no interpretador:

IDLE>>> a = 2
>>> b = 3
>>> print(a + b)
5

Note que as duas primeiras linhas não exibem nada na tela — elas apenas guardam os valores na memória. Só o print mostra o resultado.

Para números inteiros, Python tem precisão ilimitada — pode trabalhar com números enormes sem problemas. Para ponto flutuante, existem limites de precisão (por isso 3 * 0.1 pode dar 0.30000000000000004).

  • Rastrear é acompanhar o valor de cada variável a cada linha; ajuda a achar bugs.
  • input() sempre devolve texto; use int() ou float() para obter números.

4.1 A Estrutura if

Condições simples e blocos de código

🔀 Executar ou não executar?

Nem sempre todas as linhas dos programas serão executadas. Muitas vezes, será mais interessante decidir que partes do programa devem ser executadas com base no resultado de uma condição. A base dessas decisões consistirá em expressões lógicas que permitam representar escolhas em programas.

As condições servem para selecionar quando uma parte do programa deve ser ativada e quando deve ser simplesmente ignorada. Em Python, a estrutura de decisão é o if. Seu formato é:

Listagem 4.1 — Formato do ifif <condição>:
    bloco verdadeiro

O if nada mais é que o nosso "se": se a condição for verdadeira, faça alguma coisa. O bloco de código dentro do if é indicado pelo recuo (indentação) — use 4 espaços ou 1 tab.

💡
Trivia: Indentação em Python

Python é uma das poucas linguagens que utiliza o deslocamento do texto à direita (recuo) para marcar o início e o fim de um bloco. Outras linguagens usam palavras especiais como BEGIN/END (Pascal) ou chaves { } (C e Java).

🔢 Comparando dois valores

Vamos ler dois números e verificar qual é o maior. Cada if é avaliado de forma independente:

Listagem 4.2 — Condiçõesa = int(input("Primeiro valor: "))
b = int(input("Segundo valor: "))
if a > b:
    print("O primeiro número é o maior!")
if b > a:
    print("O segundo número é o maior!")

A expressão a > b será avaliada, e se o resultado for True, a linha do print será executada. Se for False, será ignorada. O mesmo acontece para b > a. Note que as linhas com if foram terminadas com dois pontos (:) — isso é obrigatório em Python.

🚗 Carro novo ou velho

Outro exemplo: solicitar a idade do carro e exibir se é novo ou velho. Carros com até 3 anos são considerados novos:

Listagem 4.3 — Carro novo ou velhoidade = int(input("Digite a idade do seu carro: "))

    print("Seu carro é novo")
if idade > 3:
    print("Seu carro é velho")

Note que as duas condições são sempre opostas: se uma for verdadeira, a outra será necessariamente falsa. Veremos uma maneira mais elegante de expressar isso na próxima aula com o else.

💰 Cálculo do Imposto de Renda

💡 A variável base guarda uma cópia do salário. Isso é necessário porque vamos modificar base durante o cálculo, mas precisamos do valor original de salário para exibi-lo no final. Os dois ifs são independentes e ambos serão avaliados.

O caminho alternativo

↔ if ... else

📞 Conta de telefone com três faixas

Nem sempre nossos programas serão tão simples. Muitas vezes, precisaremos aninhar vários ifs para obter o comportamento desejado. Aninhar, nesse caso, é utilizar um if dentro de outro.

Imagine uma operadora de telefonia com três faixas de preço: até 200 minutos custa R$ 0,20/min; entre 200 e 400 minutos, R$ 0,18/min; acima de 400 minutos, R$ 0,15/min:

5.1 A Estrutura while

Repetições e o laço while

🤔 O problema das repetições

Repetições representam a base de vários programas. São utilizadas para executar a mesma parte de um programa várias vezes, normalmente dependendo de uma condição. Por exemplo, para imprimir os números de 1 a 3, poderíamos escrever:

Listagem 5.1 — Imprimindo de 1 a 3print(1)
print(2)
print(3)

Mas se quisermos usar uma variável x e variar seu valor, poderíamos fazer:

Listagem 5.2 — Usando variávelx = 1
print(x)
x = 2
print(x)
x = 3
print(x)

Ainda melhor: incrementar x a cada passo, em vez de reatribuir:

Listagem 5.3 — Incrementando xx = 1
print(x)
x = x + 1
print(x)
x = x + 1
print(x)

Porém, se o objetivo fosse escrever 100 números, teríamos que escrever pelo menos 200 linhas! A estrutura de repetição while resolve esse problema.

🔄 A estrutura while

O while repete um bloco de código enquanto a condição for verdadeira. Seu formato é:

Listagem 5.4 — Formato do whilewhile <condição>:
    bloco

Para resolver o problema de imprimir de 1 a 3 usando while:

Listagem 5.5 — Imprimindo de 1 a 3 com whilex = 1
while x <= 3:
    print(x)
    x = x + 1

Execução passo a passo:

  1. x = 1 — x é inicializado com 1
  2. Condição x <= 3: True → executa o bloco: imprime 1, x vira 2
  3. Condição x <= 3: True → executa o bloco: imprime 2, x vira 3
  4. Condição x <= 3: True → executa o bloco: imprime 3, x vira 4
  5. Condição x <= 3: False → repetição termina
💬

💡 A linha x = x + 1 é essencial! Sem ela, a condição nunca se tornaria False e o programa rodaria para sempre — um loop infinito.

🔢 Imprimindo até um número digitado

A verdadeira vantagem do while é combinar com entrada do usuário. O contador x controla quantas repetições já foram feitas:

Listagem 5.6 — Impressão até um limite digitadofim = int(input("Digite o último número a imprimir: "))
x = 1
while x <= fim:
    print(x)
    x = x + 1

Um contador é uma variável utilizada para contar o número de ocorrências de um determinado evento. Aqui, x conta quantas repetições já foram executadas. Note que se o usuário digitar 0, a condição 1 <= 0 é falsa desde a primeira verificação e nada é impresso.

5.3 Acumuladores e break

Seção 5.2–5.3 — Acumulando valores e interrompendo repetições

📦 Acumuladores

Nem só de contadores precisamos. Em programas para calcular o total de uma soma, precisaremos de acumuladores. A diferença entre um contador e um acumulador é que nos contadores o valor adicionado é constante e, nos acumuladores, variável.

Vejamos um programa que calcula a soma de 10 números digitados pelo usuário. Nesse caso, soma é o acumulador e n é o contador:

Listagem 5.11 — Soma de 10 númerosn = 1
soma = 0
while n <= 10:
    x = int(input("Digite o %d número: " % n))
    soma = soma + x
    n = n + 1
print("Soma: %d" % soma)

Diferentemente de n, que recebe 1 a cada passagem, a variável soma é adicionada do valor digitado pelo usuário. O incremento de soma não é constante — ela acumula os valores digitados a cada repetição.

Vejamos um programa que calcula a média de cinco números digitados:

Listagem 5.12 — Cálculo de média com acumuladorx = 1
soma = 0
while x <= 5:
    n = int(input("%d Digite o número: " % x))
    soma = soma + n
    x = x + 1
print("Média: %5.2f" % (soma / 5))

A média aritmética é (n1 + n2 + n3 + n4 + n5) / 5. Em vez de usar cinco variáveis separadas, acumulamos os valores em soma conforme são lidos.

💬

💡 Acumuladores são muito úteis quando não sabemos ou não conseguimos obter o total da soma pela simples multiplicação de dois números. No cálculo da média, o valor de n pode ser diferente a cada vez que o usuário digitar um valor.

⏹ Interrompendo a repetição

Embora muito útil, a estrutura while só verifica sua condição de parada no início de cada repetição. Às vezes, é interessante poder terminar o while de dentro do bloco.

A instrução break é utilizada para interromper a execução do while independentemente do valor atual de sua condição. Vejamos um programa que lê valores e os soma até que o usuário digite 0:

Listagem 5.13 — Interrompendo a repetiçãos = 0
while True:
    v = int(input("Digite um número a somar ou 0 para sair: "))
    if v == 0:
        break
    s = s + v
print(s)

Substituímos a condição do while por True, tornando-o infinito. A instrução break só é ativada dentro do if, quando v vale zero. Enquanto v for diferente de zero, a repetição continua somando v a s.

💬

💡 O break transfere imediatamente a execução para a primeira linha após o bloco do while. É especialmente útil quando a condição de parada só pode ser verificada dentro do laço, e não no início.

5.4 Repetições Aninhadas

break avançado e while dentro de while

💵 Cédulas com break

O break pode ser combinado com if/elif para criar lógicas mais complexas. Um exemplo clássico é calcular quantas cédulas (R$ 50, R$ 20, R$ 10, R$ 5 e R$ 1) são necessárias para pagar um determinado valor:

Listagem 5.14 — Contagem de cédulasvalor = int(input("Digite o valor a pagar: "))
cédulas = 0
atual = 50
apagar = valor
while True:
    if atual <= apagar:
        apagar -= atual
        cédulas += 1
    else:
        print("%d cédula(s) de R$%d" % (cédulas, atual))
        if apagar == 0:
            break
if atual == 50:
            atual = 20
        elif atual == 20:
            atual = 10
        elif atual == 10:
            atual = 5
        elif atual == 5:
            atual = 1
        cédulas = 0

O programa subtrai repetidamente o valor da cédula atual de apagar contando quantas vezes cabe (cédulas). Quando não cabe mais, imprime a quantidade e passa para a cédula menor. O break é ativado quando não há mais nada a pagar (apagar == 0).

💡 Execute o programa com os valores: 501, 745, 384, 2, 7 e 1 para verificar se os resultados estão corretos (Exercício 5.16).

🌀 Repetições aninhadas

Podemos combinar vários while de forma a obter resultados mais interessantes. Imagine imprimir as tabuadas de multiplicação de 1 a 10. Podemos fazer isso com um while dentro de outro:

Listagem 5.15 — Impressão de tabuadastabuada = 1
while tabuada <= 10:
    número = 1
    while número <= 10:
        print("%d x %d = %d" % (tabuada, número, tabuada * número))
        número += 1
    tabuada += 1

O while externo controla a tabuada (de 1 a 10). O while interno imprime os 10 termos de cada tabuada. Note que número é reinicializado com 1 a cada nova tabuada — por isso fica dentro do bloco externo, mas antes do while interno.

Vejamos o mesmo problema sem usar repetições aninhadas, com apenas um while:

Listagem 5.16 — Tabuadas sem repetições aninhadastabuada = 1
número = 1
while tabuada <= 10:
    print("%d x %d = %d" % (tabuada, número, tabuada * número))
    número += 1
    if número == 11:
        número = 1
        tabuada += 1

Quando número chega a 11, ele é reinicializado para 1 e tabuada avança. Essa solução usa apenas um laço, mas é menos intuitiva que a versão aninhada.

💬

💡 Repetições aninhadas são naturais quando o problema tem duas dimensões: por exemplo, linhas e colunas de uma tabela. O while interno executa completamente a cada iteração do while externo.

📝 Resumo do capítulo

  • O while repete um bloco enquanto a condição for verdadeira.
  • Sem alterar a variável da condição (como x = x + 1), o laço nunca termina: é o loop infinito.
  • Um contador conta ocorrências; um acumulador soma valores ao longo das repetições.
  • break interrompe o laço na hora, mesmo que a condição ainda seja verdadeira.
  • Laços aninhados: o interno roda por completo a cada volta do externo; reinicie suas variáveis antes dele.
  • Há mais de uma solução para o mesmo problema: o importante é que o resultado esteja correto e o código, legível.

1. O que o while faz?

while significa “enquanto”: o bloco se repete até a condição virar False.

Como x nunca muda, a condição fica sempre verdadeira. Falta o x = x + 1.

Imprime 1, 2 e 3. Quando x vira 4, a condição fica falsa.

Contador é uma variável que aumenta em 1 (ou outro passo) a cada ocorrência.

Contador: c = c + 1. Acumulador: soma = soma + valor.

break sai do laço na hora, mesmo que a condição ainda seja verdadeira.

while True é infinito por natureza; o break (geralmente dentro de um if) é a saída.
